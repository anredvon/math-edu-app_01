# MathEduApp — UI Flow

## 1. 전체 앱 흐름

기본 사용자 흐름:

`앱 실행`
→ `학년 선택`
→ `중1 학습 홈`
→ `오늘의 맞춤 학습 또는 단원 선택`
→ `문제 풀이`
→ `채점`
→ `정답/오답 피드백`
→ `다음 문제 또는 재도전`
→ `학습 기록 저장`
→ `숙련도/복습 일정 업데이트`

---

## 2. 앱 실행 / 학년 선택

표시:
- 앱 제목
- 간단한 안내
- 학년 카드

학년 상태:

- 중1: 활성
- 중2: 준비중
- 중3: 준비중
- 고1: 준비중
- 고2: 준비중
- 고3: 준비중

주요 행동:
- 중1 선택
- 이후 학년은 준비중 상태 표시

선택 후:
`중1 학습 홈`으로 이동

---

## 3. 중1 학습 홈

핵심 정보:
- 오늘의 맞춤 학습
- 오늘 풀 문제 수
- 복습 문제 수
- 신규 학습 문제 수
- 현재 단원
- 이번 주 학습 진행률
- 최근 학습 결과
- 보강 필요 Skill

주요 행동:
- 오늘 학습 시작
- 단원 보기
- 오답노트
- 학습 분석
- 마이페이지

기본 Primary Action:
`오늘 학습 시작`

---

## 4. 오늘의 맞춤 학습

기본 구성 예:

- 이전 오답 복습
- 현재 단원 문제
- 약점 Skill 보강
- 마지막 확인 문제

기본 목표:
약 10~15분

학습 세션 시작 시 문제 목록을 구성하고 순차 진행한다.

---

## 5. 단원 / Skill 선택

기본 구조:

`단원`
→ `Chapter`
→ `Skill`

예:

`문자와 식`
→ `일차방정식`
→ `등식의 성질`
→ `이항`
→ `기본 일차방정식`
→ `괄호가 있는 방정식`
→ `분수가 있는 방정식`
→ `활용`

각 Skill에 표시 가능:
- 숙련도
- 최근 학습
- 복습 필요 여부
- 문제 수

Skill 선택 후:
`문제 풀이`로 이동

---

## 6. 문제 풀이

화면 구성:

상단:
- 현재 문제 번호
- 단원/Skill
- 진행률

중앙:
- 문제

하단 또는 주요 영역:
- Apple Pencil 필기 캔버스

도구:
- 펜
- 지우개
- Undo
- Redo
- 전체 지우기
- 필요 시 힌트

Primary Action:
`채점하기`

채점 후:
`채점 결과`로 이동

---

## 7. 채점 결과 — 정답

표시:
- 정답 여부
- 풀이 과정 검증 결과
- 간단한 설명
- 필요 시 캐릭터 축하

가능한 상태:
- 최종 답 정답
- 풀이 과정도 정상
- 최종 답은 정답이나 중간 과정에 오류 가능
- 부분적으로 애매한 풀이

주요 행동:
- 다음 문제
- 풀이 보기
- 필요 시 다시 보기

세션 마지막 문제라면:
`학습 완료 요약`으로 이동

---

## 8. 채점 결과 — 오답

표시:
- 최초 오류 단계
- 오답 유형
- 짧은 설명
- 단계별 힌트

예시 오답 유형:
- 개념 부족
- 부호 실수
- 계산 실수
- 이항 오류
- 문제 해석 오류
- 부주의

기본 행동 순서:

`오답 확인`
→ `1단계 힌트`
→ `재도전`

필요 시:
→ `2단계 힌트`
→ `해설 보기`

재도전 성공 시:
- 결과 기록
- 다음 문제

---

## 9. 문제 진행

일반 문제:

`풀이`
→ `채점`
→ `피드백`
→ `다음 문제`

마지막 문제:

`풀이`
→ `채점`
→ `피드백`
→ `학습 완료 요약`

자동 이동 여부와 지연 시간은 실제 UX 테스트 결과를 보고 조정한다.

---

## 10. 학습 완료 요약

표시:
- 총 문제 수
- 첫 시도 정답 수
- 재도전 성공 수
- 오답 수
- 오늘 강화된 Skill
- 다시 볼 Skill
- 다음 복습 예정

주요 행동:
- 홈으로
- 오답 다시 보기
- 추가 학습

---

## 11. 오답노트

진입:
중1 홈 → 오답노트

표시:
- 최근 오답
- 반복 오답
- Skill별 오답
- 복습 예정 문제

필터 예:
- 전체
- 단원별
- Skill별
- 개념 부족
- 계산 실수
- 부호 실수
- 문제 해석

문제 선택:
→ 기존 풀이 확인
→ 재도전 가능

---

## 12. 학습 분석

진입:
중1 홈 → 학습 분석

표시:
- Skill별 숙련도
- 단원별 진행률
- 강점
- 약점
- 반복 실수 유형
- 풀이 시간 변화
- 힌트 사용 추이
- 최근 학습 추세

분석은 단순 점수보다 Skill 변화와 유지 여부를 우선한다.

---

## 13. 마이페이지

표시 가능:
- 현재 학년
- 일일 학습 목표
- 누적 학습일
- 누적 문제 수
- 연속 학습
- AI 사용량
- 데이터 관리
- Apple Pencil 관련 설정
- 앱 설정

현재는 개인 사용자 1명을 기본으로 하며 복잡한 계정 시스템을 두지 않는다.

---

## 14. 복습 흐름

오답 또는 약한 Skill:

`오답 발생`
→ `SkillProgress 업데이트`
→ `ReviewSchedule 생성`
→ `다음 학습 세션에서 재출제`

간격 반복 예:
- 1일 후
- 3일 후
- 7일 후

실제 복습 간격은 학생의 결과에 따라 조정 가능하다.

---

## 15. AI 힌트 흐름

오답 시:

`Local Math Verification`
→ `오류 유형 확인`
→ `로컬 힌트로 충분한지 판단`

충분하면:
→ 로컬 힌트

불충분하거나 설명이 필요한 경우:
→ GPT 호출
→ 짧은 단계별 힌트

가능한 한 바로 정답 전체를 보여주지 않는다.

---

## 16. 기본 Navigation 구조

권장 개념 구조:

`GradeSelection`
→ `LearningHome`

LearningHome에서:
- TodayLearning
- UnitSkill
- WrongAnswerNotebook
- LearningAnalytics
- MyPage

문제 흐름:
`TodayLearning 또는 Skill`
→ `ProblemSolve`
→ `GradingResult`
→ `ProblemSolve / SessionSummary`

실제 SwiftUI NavigationStack 구조는 구현 단계에서 소스 구조에 맞춰 결정한다.

---

## 17. UX 원칙

- 학생이 현재 무엇을 해야 하는지 항상 명확해야 한다.
- 한 화면의 Primary Action은 가능하면 하나로 유지한다.
- 뒤로가기 때문에 학습 기록이 소실되지 않아야 한다.
- 채점 전 실수로 화면이 이동하지 않도록 한다.
- 오답 피드백은 재도전으로 자연스럽게 연결한다.
- 세션 종료 상태를 명확히 표시한다.
