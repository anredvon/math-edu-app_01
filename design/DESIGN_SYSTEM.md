# MathEduApp — Design System

## 1. 기준 디자인

이 프로젝트의 기본 UI 기준 이미지는 다음 파일이다.

`design/reference/math_app_ui_reference.png`

UI 구현 시 가능한 한 이 레퍼런스의 전체 분위기, 레이아웃 밀도, 카드 구조, 색상 역할, 캐릭터 활용 방식을 유지한다.

---

## 2. 디자인 방향

MathEduApp의 디자인은 다음 원칙을 따른다.

- iPad-first
- 밝고 부드러운 파스텔 톤
- 흰색 Rounded Card 중심
- 충분한 여백
- 친근한 학생 캐릭터와 고양이 일러스트
- 중학생에게 친근하지만 지나치게 유아틱하지 않게
- 학습 정보는 명확하고 구조적으로 표현
- 장식보다 학습 흐름과 사용성을 우선
- Apple Pencil 화면은 특히 필기 공간을 최우선

---

## 3. 색상 역할

정확한 색상 값은 구현 단계에서 Asset Catalog 또는 공통 Theme로 고정한다.

기본 역할:

- Primary Action: Blue
- Progress / Success: Green
- Review / Warning: Soft Orange
- Error: Soft Red
- Background: Very Light Pastel / Off-white
- Card: White
- Primary Text: Dark Gray / Near Black
- Secondary Text: Medium Gray

색상만으로 상태를 전달하지 않고, 텍스트 또는 아이콘을 함께 사용한다.

---

## 4. 카드 스타일

기본 UI 구성은 Rounded Rectangle 기반 카드형 레이아웃을 사용한다.

권장 원칙:

- 적절한 corner radius
- 과도한 그림자 금지
- 카드 간 충분한 간격
- 카드 내부 정보는 위계가 명확해야 함
- 한 카드에 너무 많은 기능을 넣지 않음
- iPad에서 한눈에 내용을 파악할 수 있어야 함

---

## 5. 버튼 스타일

### Primary Button
주요 행동에 사용한다.

예:
- 오늘 학습 시작
- 채점하기
- 다음 문제
- 재도전

특징:
- Blue 계열
- 충분한 높이
- 명확한 텍스트
- iPad 터치 영역 확보

### Secondary Button
보조 행동에 사용한다.

예:
- 해설 보기
- 힌트
- 나중에 하기
- 단원 보기

특징:
- Outline 또는 밝은 배경
- Primary보다 시각적 우선순위 낮게

---

## 6. Typography

기본적으로 Apple 시스템 폰트를 사용한다.

원칙:

- 화면 제목은 명확하게 크게
- 카드 제목과 본문은 충분히 구분
- 풀이 문제는 읽기 쉬운 크기 유지
- 학습 통계 숫자는 강조 가능
- 너무 작은 글자 금지
- 장문의 설명은 짧은 문단으로 분리

---

## 7. 아이콘

일반 UI 아이콘은 가능한 한 SF Symbols를 우선한다.

예:
- 홈
- 설정
- 분석
- 뒤로가기
- 체크
- 화살표
- 펜
- 지우개
- 알림
- 잠금

이미지 에셋은 캐릭터, 일러스트, 장식 요소처럼 SF Symbols로 대체하기 어려운 경우에 사용한다.

---

## 8. 캐릭터 및 일러스트

학생 캐릭터와 고양이 캐릭터는 학습 경험을 부드럽게 만드는 보조 요소다.

사용 예:
- 학습 시작
- 정답 축하
- 오답 위로
- 목표 달성
- 연속 학습
- 마이페이지
- 빈 상태 화면

원칙:
- 학습 콘텐츠보다 시각적으로 과도하게 커지지 않음
- 같은 화면에 너무 많은 캐릭터를 사용하지 않음
- 캐릭터 때문에 정보 구조가 깨지지 않도록 함
- 감정 표현은 긍정적이고 부담스럽지 않게 유지

---

## 9. Apple Pencil 문제 풀이 화면

가장 중요한 화면 중 하나다.

우선순위:

1. 문제 가독성
2. 넓은 필기 영역
3. 필기 도구 접근성
4. 채점 버튼 명확성
5. 힌트 접근성
6. 장식

필기 영역은 가능한 한 넓게 확보한다.

기본 도구:
- 펜
- 지우개
- Undo
- Redo
- 전체 지우기
- 필요 시 펜 색상/두께

장식 요소 때문에 필기 공간을 줄이지 않는다.

---

## 10. 진행률 표현

학습 진행률은 Green 계열을 기본으로 한다.

표시 예:
- 오늘 학습 진행률
- Skill 숙련도
- 단원 진도
- 주간 학습 진행

진행률은 퍼센트뿐 아니라 진행 bar 또는 명확한 상태 텍스트를 함께 제공한다.

---

## 11. 성공/오답 피드백

### 정답
- Green 계열
- 긍정적인 메시지
- 짧고 명확한 피드백
- 필요 시 캐릭터 축하 일러스트

### 오답
- 공격적이거나 과도한 Red 사용 금지
- 첫 오류 지점과 이유를 이해할 수 있도록 안내
- 실패보다는 재도전 중심
- 단계별 힌트 제공

오답 화면은 학생에게 부담을 주기보다 다음 행동을 명확히 알려야 한다.

---

## 12. 핵심 화면

현재 디자인 기준 핵심 화면은 8개다.

1. 앱 실행 / 학년 선택
2. 중1 학습 홈
3. 단원 / Skill 선택
4. Apple Pencil 문제 풀이
5. 채점 결과
6. 오답 노트
7. 학습 분석
8. 마이 페이지

화면 간 스타일은 하나의 앱처럼 일관되게 유지한다.

---

## 13. 접근성

- 충분한 터치 영역
- 충분한 글자 크기
- 색상만으로 의미 전달 금지
- 텍스트 대비 확보
- Pencil 사용 중 오작동 최소화
- 주요 버튼은 화면에서 쉽게 찾을 수 있어야 함
- 필요 시 Dynamic Type 영향 검토
