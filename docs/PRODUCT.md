# MathEduApp — Product Definition

## 1. 제품 정의
MathEduApp은 Apple Pencil로 직접 수학 문제를 풀고, 풀이 과정과 오답 패턴을 분석하여 다음 학습을 자동 구성하는 개인용 iPad 수학 학습 앱이다.

최종적으로 중1·중2·중3·고1·고2·고3까지 확장 가능한 플랫폼을 지향하되, 첫 실제 개발 및 검증 범위는 **중학교 1학년**이다.

## 2. 핵심 목표
단순히 문제를 많이 푸는 앱이 아니라 다음 학습 루프를 구현한다.

**진단 → 개념 확인 → 짧은 연습 → 오답 원인 분석 → 맞춤 재학습 → 간격을 둔 재확인**

우선순위:
1. 실제 학습 효과
2. 수학적 정확성
3. 학생이 혼자 사용할 수 있는 UX
4. 약점 Skill 발견 및 개선
5. 안정적인 학습 기록

## 3. 핵심 사용자 경험
앱을 실행하면 학생이 매번 무엇을 공부할지 결정하지 않아도 오늘 필요한 학습을 제안한다.

예시:
- 이전 오답 복습 3문제
- 현재 Skill 학습 5~6문제
- 약점 보강 2문제
- 최종 확인 1문제

기본 세션 목표는 약 10~15분이다.

## 4. 핵심 기능
- 학년 선택
- 오늘의 맞춤 학습
- 단원/Skill 탐색
- Apple Pencil 풀이
- 정답 및 풀이 과정 검증
- 단계별 힌트
- 오답 자동 분류
- 자동 오답노트
- Skill별 숙련도
- 간격 반복 복습
- 학습 분석
- AI 해설/힌트

## 5. 현재 범위
현재 활성 학년:
- 중1

준비중:
- 중2
- 중3
- 고1
- 고2
- 고3

초기 학습 PoC:
- 중1 일차방정식
- 약 30~50문제
- Apple Pencil 풀이
- 최종 답 및 단계별 검증
- 오답 유형 기록
- 복습

## 6. 비목표
초기 버전에서는 다음을 우선하지 않는다.
- App Store 공개 배포
- 다중 사용자 계정
- 자체 백엔드 서버
- 소셜 기능
- 랭킹
- 광고
- 과도한 게임화
- 전체 학년 동시 구현

## 7. 성공 기준
첫 usable version은 다음을 만족해야 한다.
- 학생이 혼자 학습을 시작할 수 있다.
- Apple Pencil로 자연스럽게 풀이할 수 있다.
- 정답 판정이 신뢰할 수 있다.
- 오답 이유를 이해할 수 있다.
- 틀린 Skill이 다시 출제된다.
- 학습 기록과 숙련도가 누적된다.
- 인터넷/AI 장애가 기본 학습 기능 전체를 막지 않는다.
