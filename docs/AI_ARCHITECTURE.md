# MathEduApp — AI Architecture

## 1. 원칙
AI는 MathEduApp의 정답 판정에 대한 유일한 권위가 아니다.

**결정적으로 검증 가능한 수학은 로컬 엔진이 우선하고, GPT는 설명과 해석을 담당한다.**

## 2. 처리 흐름
`Apple Pencil`
→ `필기/수식 인식`
→ `구조화된 풀이 단계`
→ `Local Math Verification`
→ `필요 여부 판단`
→ `GPT`
→ `Feedback`
→ `Learning Record`

## 3. 로컬 처리 우선 영역
- 최종 답 비교
- 기본 계산
- 등식의 동치성
- 명확한 단계별 수식 검증
- 복습 일정
- Skill 통계
- 호출 제한 계산

## 4. GPT 역할
필요한 경우에만 사용한다.
- 오답 원인 설명
- 단계별 힌트
- 학생 수준에 맞춘 해설
- 애매한 필기/풀이 해석 보조
- 오답 유형 분류 보조

정답이고 로컬 엔진이 충분한 확신으로 검증한 문제는 GPT 호출을 생략할 수 있다.

## 5. 호출 제한
초기 운영값:
- 최대 20회/일
- 최대 500회/월

실제 사용량 및 비용을 확인한 후 변경 가능하다.

## 6. 개인정보 최소화
GPT에 불필요한 개인 데이터를 보내지 않는다.

전송 가능:
- 현재 문제
- 인식된 현재 풀이
- 로컬 검증 결과
- 필요한 경우 해당 Skill의 최소 최근 오류 정보

기본적으로 전송하지 않음:
- 학생 이름
- 학교
- 전체 학습 이력
- 다른 개인 식별 정보

## 7. API Key
OpenAI API Key를 앱 소스/번들에 직접 포함하지 않는 구조를 사용한다.

권장 구조:
`iPad → lightweight proxy → OpenAI API → proxy → iPad`

초기 Proxy 후보:
- Cloudflare Workers

Proxy 역할:
- API Key 보호
- 요청 검증
- 사용량 제한
- 모델 라우팅
- OpenAI 호출

문제은행과 전체 학생 기록은 Proxy에 저장하지 않는다.

## 8. 장애 대응
GPT 호출 실패 시:
- 기본 채점은 계속 동작한다.
- 저장된 기본 힌트/해설을 사용할 수 있다.
- AI 분석 실패를 정답/오답 판정 실패로 취급하지 않는다.
